# 能力规格：example-note（示例笔记）

> 示例能力，用来演示规格、契约、迁移、实现与测试之间的对应关系。业务开发开始后可以删除整个示例（见 `docs/context/architecture.md`）。

## 概述

用户可以新建、查询、删除笔记。笔记先保存为草稿，之后可以发布。

## 角色与权限

| 角色 | 可以做什么 |
| :--- | :--- |
| 登录用户 | 新建、查询、删除笔记 |

## 数据对象与关键字段

| 对象 | 字段 | 说明 |
| :--- | :--- | :--- |
| 笔记 | 标题 | 必填，1～64 个字符 |
| 笔记 | 内容 | 选填，不超过 2000 个字符 |
| 笔记 | 状态 | 草稿（DRAFT）、已发布（PUBLISHED） |

## 状态与流转

```text
草稿 ──发布──► 已发布
```

## 业务规则

- **BR-example-note-01**：新建的笔记一律为草稿。
- **BR-example-note-02**：已发布的笔记不能重复发布。
- **BR-example-note-03**：删除为逻辑删除，删除后不能再查询到。

## 验收标准

### AC-example-note-01：新建笔记为草稿

- 关联规则：BR-example-note-01
- 前提：无
- 操作：新建一条笔记
- 结果：笔记状态为草稿

### AC-example-note-02：已发布的笔记不能重复发布

- 关联规则：BR-example-note-02
- 前提：笔记已发布
- 操作：再次发布
- 结果：提示"笔记已发布，不能重复发布"（错误码 B9902），状态不变

### AC-example-note-03：新建后可以查询到

- 关联规则：BR-example-note-01
- 前提：无
- 操作：新建笔记后按编号查询
- 结果：返回该笔记，编号以字符串返回，状态为草稿

### AC-example-note-04：标题为空时不能保存

- 关联规则：数据对象"标题必填"
- 前提：无
- 操作：标题为空时新建
- 结果：返回 400，并指出"标题"字段的错误

### AC-example-note-05：删除后查询不到

- 关联规则：BR-example-note-03
- 前提：笔记存在
- 操作：删除后按编号查询
- 结果：返回 404，错误码 B9901

## 不在范围内

- 笔记的编辑、发布接口（只在领域层演示发布规则）。
- 权限控制。
